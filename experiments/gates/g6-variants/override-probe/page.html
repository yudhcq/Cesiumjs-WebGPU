Feasibility probe for the G-6 fix (T025 over-budget). It answers one question with device numbers: is a new WGSL override value on an already-parsed module cheaper than a new module text? Three workloads are measured on the same adapter with the same timing discipline as g6-variants/driver.js (including the popErrorScope validation round trip), plus a trivial-module floor so a per-pipeline constant cost cannot be mistaken for shader size. This page is not a gate: it is the experiment that decides the route, and its report is archived as evidence.
