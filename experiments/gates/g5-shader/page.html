G-5 gate device page (tasks.md T022/T023). It compiles the WGSL emitted by experiments/gates/g5-shader/wgsl-emitter.mjs for every variant of the MVP-reachable define matrix and creates a real GPURenderPipeline for each distinct module pair; in mvp mode it additionally renders the fixed terrain scene and reads the frame back. The runner (tools/shader-verify.mjs) collects the result through window.__g5.
